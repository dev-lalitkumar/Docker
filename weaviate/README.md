# Weaviate Docker Compose

This folder contains the Docker Compose configuration for running Weaviate.

## Usage

1.  Navigate to this directory:

    ```bash
    cd weaviate
    ```

2.  Start the service:
    ```bash
    docker compose up -d
    ```

## Connection Details

- **Port**: 8080 (Standard Weaviate port)
- **gRPC Port**: 50051
